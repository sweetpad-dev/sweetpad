# Portable archive codecs

These sources are compiled into a private host library when SDK archive import needs them.
The CLI executable keeps its static Linux distribution format.

- LZFSE: Apple, BSD 3-Clause, revision `e634ca58b4821d9f3d560cdc6df5dec02ffc93fd` of https://github.com/lzfse/lzfse.
- LZRAVEN: anat0m1a, 0BSD, revision `700b88c4b2e1b1d96e499d172dfa0b8e5d9134ab` of https://github.com/anat0m1a/liblzraven.

The original notices and licenses are retained beside the sources.
Decoder conformance tests use archives generated by Apple's command-line tools.
